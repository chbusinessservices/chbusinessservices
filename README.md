## 🚀 Quickstart

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed locally (v1.2+ recommended).

```bash
curl -fsSL https://bun.sh/install | bash
```

### Setup & Run

1. **Clone Repository**
```bash
git clone git@github.com:chbusinessservices/chbusinessservices.git
cd chbusinessservices
```

2. **Install Dependencies**
```bash
bun install
```

3. **Start Development Server**
```bash
bun run serve.ts
```

4. **Production Build & Deployment**
```bash
# Build entry for Vercel
bun run build-vercel.sh

# Push build to live production
bun run go-live.sh
```
